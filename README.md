### ⚙️ Installation & Setup

<details>
<summary><b>Standard Blender Addon Installation (.zip)</b></summary>
<br>

1. Head to the target repository and download the repository as a `.zip` file from the **Releases** tab (or via `Code > Download ZIP`).
2. Launch **Blender**.
3. Navigate to **Edit** > **Preferences** > **Add-ons** (or **Get Extensions** / **Install from Disk**).
4. Click **Install...**, navigate to your downloaded `.zip`, and select it.
5. Check the box beside the addon name to enable it.
</details>
